# Vicky · Portfolio

Personal portfolio of Vicky, B.Tech CSE student at J.C. Bose University of Science and Technology, YMCA, Faridabad.

**Live:** https://vicky-cse.vercel.app

- Plain HTML, CSS and JavaScript, with no build step and no dependencies apart from one QR code library.
- Hosted on Vercel from this repository.
- Security headers (Content-Security-Policy, X-Frame-Options, HSTS and others) are set in `vercel.json`.

## Structure

| Path | What it is |
|---|---|
| `index.html` | The portfolio page |
| `app.js` | Theme toggle, copy email, QR code, certificate viewer |
| `resume.html` | Web version of the resume |
| `certs/` | Certificate images and the ShilpSetu QR code |
| `vercel.json` | Security headers |
